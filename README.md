# 풍속 예측 실험

ASOS 시간별 관측 자료로 다음 1시간 풍속을 예측하고, 현재 풍속 유지·선형 회귀·랜덤 포레스트의 성능을 비교합니다. 모든 시각은 KST이며 CSV의 시각 문자열은 시간대 정보가 없는 KST 기준입니다.

## 입력 자료

- `asos_108_2023_2024.csv`: 시간별 관측 자료
- `wind_dataset.csv`: 학습 및 평가용 입력/정답 자료

## 설치

Python 3.12 이상에서 필요한 패키지를 설치합니다.

```powershell
python -m pip install scikit-learn matplotlib
```

## 실행 순서

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
python .\create_wind_dataset.py
python .\create_wind_predictions.py
python .\create_prediction_week_plot.py
```

첫 번째 명령은 원본 관측 시각을 시간당 한 행으로 정렬하고 누락 시각을 빈 시간대로 둡니다. 각 행의 입력은 현재 풍속, 현재 기온·습도, 1시간 전과 2시간 전 풍속이며, 정답은 1시간 뒤 실제 풍속입니다. 필요한 값이 없는 행은 학습 자료에서 제외합니다.

두 번째 명령은 정답 시각이 2023년 1월부터 2024년 11월까지인 행으로 모델을 학습하고, 2024년 12월 1일부터 31일까지의 행으로 평가합니다. 자료를 시간순으로 처리하며 평가 구간에서는 재학습하지 않습니다. 비교 방법은 다음과 같습니다.

- **현재 풍속 유지:** 현재 풍속을 다음 시각의 예측값으로 사용
- **선형 회귀:** 현재 풍속, 1·2시간 전 풍속, 현재 기온·습도 사용. 음수 예측은 0으로 처리
- **랜덤 포레스트:** 같은 5개 입력 사용, 나무 100개, 최대 깊이 6, 끝가지 최소 표본 5개, `random_state=42`

세 방법의 MAE와 기준 예측 대비 차이를 출력하고, 각 평가 행의 예측 결과를 `predictions.csv`에 저장합니다.

세 번째 명령은 `predictions.csv`에서 정답 시각이 2024년 12월 1일 00시부터 12월 7일 23시까지인 결과를 비교 그래프로 만들고 `prediction_week.png`로 저장합니다. MAE는 해당 주가 아닌 12월 전체 평가 행을 사용합니다.

## 생성 파일

- `wind_dataset.csv`: 시간 간격을 맞춘 입력/정답 데이터
- `predictions.csv`: 예측 시각, 정답 시각, 실제값, 세 방법의 예측값
- `prediction_week.png`: 12월 1~7일 실제값과 세 예측 방법의 비교 그래프
